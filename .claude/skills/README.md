# Project skills

Project-scoped [Claude Code skills](https://code.claude.com/docs) for this app.
They load automatically for anyone using Claude Code in this repo and encode the
UI/UX standards for our Arabic (RTL) Next.js + Tailwind frontend.

| Skill | Use it when |
| --- | --- |
| **frontend-design-system** | Building or editing any component/page — enforces shared tokens, RTL-correct styling, and per-state design. |
| **web-accessibility** | Working on forms, keyboard nav, contrast, ARIA, screen-reader semantics (WCAG 2.1 AA). |
| **ui-design-review** | Critiquing a screen before it ships — prioritized, actionable UI/UX feedback. |

Each skill lives in its own folder as `SKILL.md`. Claude selects them automatically
based on the task; you can also invoke one by name.
